# 目录校验和工具
用于计算指定目录下所有文件的哈希值，统计文件变化并生成报告。

计算当前目录的校验和，默认采用`sha256`校验算法：
```bash
python main.py [指定一个目录]
```

校验当前目录的完整性，默认采用`sha256`校验算法：
```bash
python main.py [指定一个目录] -v
```
带上参数`-v`会自动寻找目录下生成的校验和文件用于比对。

指定校验算法，目前仅支持`[md5, sha256, sha384, sha512]`。
```bash
python main.py [指定一个目录] --hash [校验算法]
```
